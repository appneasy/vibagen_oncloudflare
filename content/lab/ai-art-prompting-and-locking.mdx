## พรอมต์ = 80% ของงาน ไม่ใช่ตัวโมเดล

พาร์ตนี้คือของจริงที่คนอยากรู้ที่สุด: **พรอมต์เขียนยังไง** และทำยังไงให้ตัวละคร **เหมือนเดิมทุกภาพ** ข้าม 40 รูป — ทุกตัวอย่างในบทความนี้คือพรอมต์ที่ใช้จริง

---

## กายวิภาคพรอมต์ที่ดี (สูตร 5 บล็อก)

พรอมต์ที่คุมได้ ไม่ใช่การพิมพ์ยาว ๆ มั่ว ๆ แต่ประกอบจาก **5 ส่วน** ที่แยกหน้าที่กันชัด:

| บล็อก | ทำหน้าที่ | เปลี่ยนบ่อยไหม |
|---|---|---|
| **STYLE** | สไตล์/ลายเส้น/โทนสี | 🔒 ล็อก ไม่เปลี่ยน |
| **SUBJECT** | ตัวละคร + ท่าทาง + อารมณ์ | เปลี่ยนทุกภาพ |
| **COMPOSITION** | วางตรงไหน เว้นที่ว่างตรงไหน | เปลี่ยนตามภาพ |
| **BACKGROUND** | พื้นหลัง (เราใช้แมเจนต้าทึบ) | ล็อก |
| **NEGATIVE** | ห้ามมีอะไร | ล็อก |

**ตัวอย่างจริง — 1 ภาพสติกเกอร์ (ก็อปไปปรับได้):**

:::prompt
STYLE: มาสคอตน่ารักสไตล์ LINE Friends, ตัวขาวกลม, เส้นขอบดำบาง #1E1E1E,
       หน้ามีตา/จมูก/ปาก, แก้มเป็นลาย "ก้นหอย" คอรัล (ลายเซ็นเฉพาะตัว),
       หมวกเซฟตี้เหลือง + เสื้อ shop น้ำเงิน   ← ส่วนที่ล็อก
SUBJECT: ท่าโบกมือทักทาย ยิ้มร่าเริง
COMPOSITION: วางตัวมุมล่างซ้าย เปิดที่มุมบนขวาให้ข้อความ
TEXT: เขียนคำไทย "สวัสดีครับ" เป๊ะ ฟอนต์สไตล์ Kanit หนา ทันสมัย
BACKGROUND: เติมแมเจนต้าทึบ #FF00FF เต็มเฟรม
NEGATIVE: ห้ามมีตัวหนังสืออื่น, ห้ามขอบสติกเกอร์สีขาว
:::

> **เคล็ดลับ:** แยก "STYLE (ล็อก)" ออกจาก "SUBJECT (เปลี่ยน)" ให้ชัด → เปลี่ยนแค่ subject ก็ได้ภาพใหม่ที่ยังเป็นตัวละครเดิม

---

## เทคนิค #1: "พื้นแมเจนต้า" แทนพื้นโปร่งใส

ปัญหาจริง: สั่ง "พื้นโปร่งใส" ตรง ๆ กับ AI → มัน **สุ่มคืนภาพทึบ + วาดลายตารางหลอก** (เหมือนโปร่งใสแต่จริง ๆ ทึบ) ตรวจด้วยตาไม่เห็น เสียงานทั้งชุด

:::insight{number=1 title="เติมแมเจนต้า แล้วค่อยคีย์ออกทีหลัง"}
1. สั่งให้เติมพื้น **แมเจนต้าทึบ #FF00FF** (สีนี้โมเดลเติมได้นิ่งมาก)

2. เอามาผ่านสคริปต์ **chroma-key ลบสีแมเจนต้า** เป็นพื้นโปร่งใส (soft matte + ลบขอบชมพูฟุ้ง)

3. ได้ขอบเนียน แม้ตัวละครมีขนฟู

**กฎเหล็ก:** อย่าให้ตัวละครมีสีชมพู/แมเจนต้า เพราะจะโดนคีย์ออกไปด้วย
:::

## เทคนิค #2: ฝังตัวหนังสือไทยให้สะกดถูก

- ให้ AI "วาดตัวอักษร" ตอนเจนเลย (ไม่ต้องแปะทีหลัง) — สั่งฟอนต์ฟรีที่ใช้เชิงพาณิชย์ได้ เช่น **Kanit** (โมเดิร์น) / Itim / Mali
- **เน้นขนาดต่างกัน** สร้างลำดับสายตา เช่น "สู้" ตัวใหญ่ + "ต่อไป" ตัวเล็ก
- **สะกดคำสั้น–ชัด** คำยาว/ผสมอังกฤษ AI มักเพี้ยน → QC ทุกรูป คำไหนเพี้ยนบ่อยให้เปลี่ยนคำ
- พร็อพในภาพ **เลี่ยงตัวหนังสือทั้งหมด** (นาฬิกาไม่มีเลข, กระดาษเปล่า) กัน AI สะกดมั่ว

## หัวใจ: ล็อกคาแรคเตอร์ให้เหมือนเดิมทุกภาพ

โจทย์ยากสุดของสติกเกอร์ = ตัวละครต้อง **นิ่ง** ข้าม 40 ภาพ (ท่าต่างกันแต่เป็นตัวเดียวกัน)

**ขั้น 1 — หา "master" ให้ได้ก่อน (วนแก้ทีละรูป)** ยิงรูปต้นแบบไม่มีข้อความ แล้วปรับทีละจุดจนลงตัว โปรเจกต์นี้วนจาก v2 → v6:

- v2: เสื้อ shop สีเทา → ปรับเป็นน้ำเงิน
- v3: เปิดอกเกินไป → ปรับทรง
- v4–v5: ปรับกระดุม/ปกเสื้อ/แถบสะท้อนแสง
- **v6: ลงตัว → ล็อกเป็น master** 🔒

**ขั้น 2 — เขียน "STYLE BLOCK" ตายตัว** พอได้ master → ถอดลักษณะทั้งหมดเป็นบล็อกเดียว เก็บในโค้ด → ทุกภาพในชุดใช้บล็อกนี้ เปลี่ยนแค่ท่า/คำ

**ขั้น 3 — QC + re-roll เฉพาะที่หลุด** บางองค์ประกอบ AI สุ่ม (เช่น ลายก้นหอยบนแก้มออก ~50/50) → ตรวจทุกรูป หลุดมากค่อยยิงใหม่ หลุดนิดหน่อยยอมรับได้ (กฎ "แค่ไหนพอ")

:::lesson{title="ลายเซ็นเฉพาะตัว = อาวุธลับกันลอก"}
เราออกแบบ "ก้นหอยคอรัล" เป็น maker's mark ติดทุกงาน (แก้มตัวละคร / จุดเด่น 3 ตำแหน่ง) → ทั้งพอร์ตมี DNA เดียวกัน คนเห็นก็รู้ว่าใครทำ = กันลอกเลียน + สร้างแบรนด์

ต่อให้ทำไว้ใช้ในองค์กร ลายเซ็นนี้ก็ทำให้สื่อของทีมดู "เป็นชุดเดียวกัน" ทันที
:::

## เทคนิค #3: "ถอดสไตล์" จากงานที่ชอบ (อย่างมีจริยธรรม)

อยากได้อารมณ์แบบงานที่เห็นในเน็ต? เรา **ถอดเฉพาะ "เทคนิค" ไม่ลอกตัวละคร**:

1. ดูภาพอ้างอิง → วิเคราะห์ว่า "เทคนิคอะไร" (สีน้ำ+เส้นหมึก / แฟลตเหลี่ยม / เส้นปั่น scribble)
2. เขียนเป็น STYLE BLOCK แบบทั่วไป (บรรยายเทคนิค ไม่ก็อปตัวละคร)
3. **สร้างตัวละครใหม่ของเราเอง** + ใส่ลายเซ็นเราเข้าไป
4. ⚠️ **ห้ามเอารูปต้นฉบับคนอื่นยิงเข้า AI เป็น input reference เด็ดขาด**

**ตัวอย่าง STYLE BLOCK ที่ถอดมา (สายสีน้ำ):**

:::prompt
สีน้ำ (watercolor) โปร่งแสง + เส้นหมึกปากกา (ink) บนกระดาษ cold-press,
ตากลมโตมีไฮไลต์คู่, ขนฟูละลายเป็นละอองสีตรงขอบ,
ลายเซ็น: พื้นหลังแบ่งครึ่งทแยง 2 โทน (ฟ้า-ชมพู) + ละอองสีสาดรอบตัว
:::

เปลี่ยน subject เป็นอะไรก็ได้ (แมว / สิงโตใส่ชุดซาฟารี) ก็ยังเป็น "สไตล์เรา"
