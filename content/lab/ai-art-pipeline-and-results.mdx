## จากพรอมต์ → ขายได้จริง ทำเป็นสายพานได้

พาร์ตสุดท้าย: ร้อยทุกอย่างเป็น "สายพานผลิต" ที่ทำซ้ำได้ทุกชุด + ผลจริง + สิ่งที่ได้เรียนรู้

---

## สายการผลิต end-to-end

```
1. spec      → ออกแบบรายการภาพ (คำ/ท่า/พร็อพ) ทั้งชุดเป็นไฟล์เดียว
2. GEN       → kie เรนเดอร์บนพื้นแมเจนต้า (ยิงเป็น batch ~6 รูป)
3. QC        → ตรวจทุกภาพ: คำสะกดถูก? ตัวละครนิ่ง? ลายเซ็นครบ? (re-roll ที่หลุด)
4. KEY       → ลบพื้นแมเจนต้า → พื้นโปร่งใส (chroma-key soft matte)
5. FINALIZE  → ครอป/ย่อเป็นขนาดสเปก (สติกเกอร์ 370×320) + ฝัง metadata เจ้าของ
6. PACKAGE   → ทำภาพหน้าปก (main) + แท็บ (tab) + zip ทั้งชุด
7. SUBMIT    → คนอัปขึ้นแพลตฟอร์ม + ตั้งราคา + ติ๊ก "ใช้ AI" + ส่งพิจารณา
```

> ขั้น 1–6 = AI/สคริปต์ทำ · ขั้น 7 = **คนทำเองเสมอ** (ธุรกรรม + ความรับผิดชอบทางกฎหมาย)

**เคล็ด metadata:** ฝังชื่อเจ้าของ/ลิขสิทธิ์/ปีลงในไฟล์ PNG (tEXt + XMP) ทุกไฟล์ = พิสูจน์ความเป็นเจ้าของภายหลังได้

---

## ผลลัพธ์จริง

| ผลงาน | สไตล์ | สถานะ |
|---|---|---|
| สติกเกอร์ชุด 1 "น้องโอที ชีวิตโรงงาน" | flat มาสคอต | ✅ ขายแล้วบน LINE STORE |
| สติกเกอร์ชุด 2 "น้องโอที ออฟฟิศ-โรงงาน" (40 รูป) | flat มาสคอต | ⏳ ส่งพิจารณาแล้ว |
| ไลน์ clipart (watercolor / flat / scribble) | 3 สไตล์ | 🧪 พิสูจน์สไตล์แล้ว |

**สิ่งที่ทำให้ "ใช้ได้จริง":** ทำเป็น **ชุด/ซีรีส์** สไตล์เดียวกัน + เจาะกลุ่มเฉพาะ (คนทำงานโรงงาน/ออฟฟิศ) + **มีลายเซ็นเฉพาะ** ไม่ generic

> และย้ำอีกครั้ง — **ต่อให้ไม่ขาย** ชุดสติกเกอร์แบรนด์ตัวเองก็เอาไปใช้ในองค์กรได้ทันที (กลุ่มไลน์ทีม, สื่อสารภายใน, ของแจกลูกค้า)

## สายเวกเตอร์ (สำหรับขายสต็อกภาพ เช่น Freepik)

งานแฟลตแปลงเป็นไฟล์เวกเตอร์ (SVG) ขายได้ — ทดสอบ 2 เครื่องมือ:

| เครื่องมือ | ราคา | คุณภาพ | เหมาะกับ |
|---|---|---|---|
| **vtracer** | ฟรี (local) | ดีระดับหนึ่ง (แฟลตสะอาด) | เริ่มต้น / งบ 0 |
| **Vectorizer.AI** | รายเดือน ไม่จำกัด | เนียนกว่ามาก (โค้งสวย path น้อย) | เอาจริง ผลิตเป็นชุด |

:::insight{number=1 title="ออกแบบ 'เผื่อเวกเตอร์' ตั้งแต่ต้น"}
- ✅ **แฟลต/สีน้อย → trace สะอาด** (ยิ่งสีน้อย path ยิ่งน้อย ไฟล์เบา)
- ❌ **scribble/สีฟุ้ง → หนักมาก** (9,000+ paths) = ไม่คุ้ม → เก็บเป็น PNG แทน
- 💡 ล็อกพาเลตสีน้อย + เส้นคม ตั้งแต่ตอนออกแบบ master
:::

## แนวคิด "ประกอบจาก building blocks"

พอมีของครบ เราไม่เริ่มใหม่ทุกงาน แต่ **หยิบชิ้นส่วนมาผสม**:

```
ไลน์สไตล์ (watercolor/flat/scribble)
  + ตัวสัตว์ (แมว/หมา/สิงโต...)
  + ธีม/เครื่องแต่งกาย (ซาฟารี/ออฟฟิศ...)
  + คู่สี/พาเลต
  + ลายเซ็นก้นหอย (maker's mark)
  = งานใหม่ที่ยังเป็น "สไตล์เรา"
```

ตัวอย่างจริง: scribble + สิงโตยืน + ชุดซาฟารี + ก้นหอย 3 จุด = ภาพเดียวที่มีเอกลักษณ์สูงมาก **ในไม่กี่นาที**

## บทเรียนสำคัญ (ถ้าจะทำตาม)

**1. หา master ให้นิ่งก่อน** แล้วค่อยขยายเป็นชุด — อย่ายิง 40 รูปทั้งที่ตัวละครยังไม่นิ่ง

**2. พรอมต์ = 80% ของงาน** ไม่ใช่ตัวโมเดล

**3. QC ทุกภาพด้วยตาคน** — AI เพี้ยนได้ (คำ, ลายเซ็น, นิ้ว/มือ)

**4. รู้จักพอ** — ยอมรับความไม่สมบูรณ์ที่ AI สุ่ม, ใช้เครื่องมือ "ดีพอ" ก่อน

**5. ลายเซ็นเฉพาะตัว** สร้างแบรนด์ + กันลอก

**6. ซื่อสัตย์เรื่อง AI** — ติ๊ก "ใช้ AI" ตามจริงเสมอ (ทั้ง LINE และ Freepik ต้องการ), เลี่ยงหน้าคนจริง/แบรนด์/ลิขสิทธิ์คนอื่น

**7. เก็บทุกอย่างเป็นระบบ** (สเปก, พรอมต์, master, ความจำโปรเจกต์) → ทำงานต่อได้เร็ว

:::lesson{title="หัวใจที่ AI แทนไม่ได้"}
AI ทำให้ "เร็วและถูก" แต่ **คนคือคนกำหนดรสนิยม ทิศทาง และความรับผิดชอบ** — พรอมต์คิดโดยคน, เคาะโดยคน, ธุรกรรมโดยคน นี่คือส่วนที่โมเดลแทนไม่ได้
:::
